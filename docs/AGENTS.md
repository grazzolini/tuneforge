# AGENTS.md (Docs)

Scope: `docs/`

Follow root `AGENTS.md` plus the rules below for documentation updates.

## Documentation Structure

- Keep architecture details in `ARCHITECTURE.md`.
- Keep API-facing behavior in `API.md`.
- Keep roadmap content in `ROADMAP.md`.
- Keep product-level functional scope in `SPEC.md`.
- Keep mobile-specific planning in `MOBILE.md`.

## Editing Rules

- Prefer updating existing docs over creating new markdown files.
- Keep docs aligned with current implementation and workflows.
- Avoid speculative sections unless clearly marked as proposed/future work.
- When commands are documented, prefer repo-root command examples unless folder-local context is necessary.
